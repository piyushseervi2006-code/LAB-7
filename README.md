# Simple Calculator

A beginner-friendly calculator webpage that performs addition, subtraction, multiplication, and division. It uses HTML for the form, CSS for the design, and JavaScript for the calculations.

## Features

- Takes two number inputs
- Performs four basic math operations
- Shows the result on the page
- Checks that both numbers are entered
- Prevents division by zero
- Responsive layout for smaller screens

## Files

```text
.
├── index.html   # Calculator form and page structure
├── style.css    # Page colors, layout, and styling
├── script.js    # Calculator operations
└── README.md    # Project information
```

## Run the calculator

Download or clone this repository, then open `index.html` in a web browser. No installation or build tools are needed.

## How to use it

1. Enter a number in each field.
2. Select **Add**, **Subtract**, **Multiply**, or **Divide**.
3. Read the result shown below the buttons.

## Publish with GitHub Pages

1. Open the repository on GitHub and select **Settings**.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then select **Save**.
5. When publishing is complete, open the site link shown in the Pages settings.
